# Flutter Theme Builder

Use this skill when building or completing the app theme in theme.dart.

## Steps

1. Read the existing theme.dart file first
2. Build a full Material 3 ColorScheme with a travel-inspired palette (blue, teal, warm white)
3. Define: primaryColor, backgroundColor, cardColor, textTheme, appBarTheme, elevatedButtonTheme, inputDecorationTheme
4. Use material_color_utilities (already in pubspec) for color generation
5. Make sure the theme is applied in app.dart via MaterialApp.router's theme parameter
6. Trigger hot reload and take a screenshot to verify the new theme is visible
