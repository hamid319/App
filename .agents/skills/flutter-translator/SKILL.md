# German to English Translator

Use this skill when any Dart file contains German text strings.

## Steps

1. Search the entire codebase for German words: Entdecke, Überspringen, Fehler, Zurück, Ort, nicht gefunden, Weiter, Anmelden
2. For each file found, replace all German strings with English equivalents
3. Do not change any logic, only the string values
4. Run `flutter analyze` after changes
5. Trigger hot reload and screenshot to confirm UI text changed
